# README

1. You need create subfolder for each project to this folder
2. (optional) You can create subfolders for each project subfolder if you want the images in a different gallery
3. (optional) You need give this subfolder path to ImageGallery component in the projects mdx files by subdirPath prop
4. Put project images to these created subfolder. Supported image file extensions are .jpg, .jpeg, .png and .webp
5. Delete this README.md file (if you want)
